# «Бірге» MVP: требования

Функциональные и нефункциональные требования к MVP. Архитектура и стек — в [`../architecture.md`](../architecture.md), решения — в [`../adr/`](../adr/).
Приёмку по разделу 10 подписывают владелец продукта и, для пунктов про ИИ, психолог проекта.

## 0. Непереговорные требования

- N1. Кризисный ответ и эскалация работают всегда, в том числе когда API ИИ недоступен.
- N2. Персональные данные не уходят в ИИ: только обезличенный текст и только при согласии `ai_crossborder`.
- N3. Персональные данные хранятся на сервере в РК.
- N4. В репозитории нет секретов и реальных данных, включая всю историю коммитов.
- N5. Бот никогда не предлагает оставить ребёнка с человеком без статуса «знакомы лично» с мамой или вне списка доверенных лиц.

Если не успеваем, режем в таком порядке: сначала «Делимся», потом «Мои права». N1–N5, согласия и обезличивание не режутся.

## 1. Рамки

**В MVP:** онбординг и согласия; «Как я»; ИИ-помощник; «Мамы рядом» («Чай», чаты района и тематические, личные чаты); «Делимся» (объявления и специалисты); SOS и план ЧС; «Мои права»; админка для сотрудников. Клиенты — мобильное приложение (iOS, Android) и веб.

**Вне MVP**, но архитектура должна позволять добавить без переписывания: няни и агентства, совместная няня, обмен часами, экстренный присмотр, платежи, eGov, запись к психологу, голос, интеграции с внешними каталогами.

## 2. Стек

Стек и инфраструктура описаны в [`../architecture.md`](../architecture.md).
Бизнес-логика живёт в доменных модулях, клиенты (приложение мамы, админка) — тонкие. У пользователя есть пара `channel` + `channel_user_id`, чтобы позже добавить второй канал.

## 3. Роли и доступ

Роли: mom, mentor, psychologist, lawyer, moderator, admin. У одного человека может быть несколько ролей.

| Функция | new | verified | знакомы лично (пара) |
|---|---|---|---|
| «Как я», ИИ, «Права», чтение каталогов | ✓ | ✓ | ✓ |
| «Чай», чаты, создание объявлений и отзывов | — | ✓ | ✓ |
| SOS модератору и доверенным лицам | ✓ | ✓ | ✓ |
| SOS в ленту района | — | ✓ | ✓ |
| Быть доверенным лицом в плане ЧС | — | — | ✓ |

- Переход new → verified: модератор подтверждает после видеозвонка.
- «Знакомы лично» — свойство пары мам, а не одной мамы.

## 4. Функции

Общее для всех экранов:
- Главное меню из 6 кнопок: «Как я», «Поговорить», «Мамы рядом», «Делимся», «Мои права», «SOS».
- Служебные команды: язык, профиль, «Удалить мои данные», помощь.
- Тексты до 3 строк, на «вы», все строки в локализации.

### 4.1 Онбординг
1. Выбор языка kk/ru.
2. Приветствие с фразой «я — бот и ИИ-помощник, не врач и не психолог».
3. Согласия, у каждого сохраняется версия:
   - `data_processing` — обязательно;
   - `ai_crossborder` — без него недоступно «Поговорить»;
   - `research` — по желанию.
4. Профиль: имя, город и район из списка, дети (год рождения и особенности из справочника, можно «не хочу указывать», можно несколько детей).
5. Первая проверка состояния, её можно отложить.
6. Главное меню. Статус — new, есть кнопка «Подтвердить профиль», она создаёт заявку модератору.

Приёмка: онбординг занимает не больше 2 минут на каждом языке; без `data_processing` дальше не пройти.

### 4.2 «Как я»
- Раз в неделю напоминание в выбранный мамой день и час (Asia/Almaty).
- 8 вопросов (PHQ-4 + PSS-4), по одному на экран, ответы кнопками. Тексты вопросов и пороги лежат в конфиге.
- После проверки: короткая обратная связь без диагнозов, график за 8 недель, одно предложение (практика, «Чай» или «Поговорить»).
- `flag=elevated` → предложение связаться с психологом; при «да» создаётся эскалация с `source=checkin`.
- `flag=crisis` → кризисный ответ (§5.4).
- «Практики»: 5–10 аудиофайлов на каждом языке.

### 4.3 «Поговорить»
- Свободный диалог, выход по кнопке «В меню». Пока ждём ответ, показывается «печатает…».
- Лимит 50 сообщений в сутки, значение в конфиге.
- Под каждым ответом кнопки «Помогло / Не помогло» и «Связаться с человеком» (создаёт эскалацию).

### 4.4 «Мамы рядом»
- **«Чай»**: мама выбирает формат (встреча или звонок) и предпочтения → создаётся `tea_request`.
- **Подбор** раз в час. Веса из конфига: район +3, возраст ребёнка ±2 года +2, общая особенность +2, язык +1.
- **Карточка пары** без контактов (имя, район, возраст ребёнка, общие особенности) и кнопки «Давайте / Не сейчас». После двух «Давайте» открывается личный чат; телефоны не раскрываются. Запрос истекает через 7 дней.
- **Через 3 дня** вопрос «Вы встретились?». Два «да» → пара получает статус «знакомы лично». Под вопросом кнопка «Пожаловаться».
- **Чаты** — внутри приложения (ADR-0016):
  - групповые: чат района и тематические по типу ООП, только для verified; мама вступает и выходит сама;
  - личные: после двух «Давайте» в «Чае» и после того, как мама открыла контакт откликнувшемуся на SOS. Телефоны не раскрываются;
  - пост-модерация с удержанием: первые сообщения новичков, ссылки и телефоны; жалоба, блокировка, мут; наставница модерирует свою комнату с ограниченными правами;
  - кризисный словарь проверяет каждое сообщение: ответ автору лично, эскалация модератору;
  - только текст; без «прочитано» и «печатает»; хранение: групповые 1 год, личные 90 дней.

### 4.5 «Делимся»
- **Объявления**:
  - Создание: тип (отдам / обменяю / ищу) → категория → заголовок → описание → фото → район. Перед созданием показываются правила.
  - Статусы: pending → модерация → active. Через 30 дней объявление закрывается автоматически.
  - Лента: фильтры по типу, категории, району; по 5 объявлений на экран.
  - «Написать автору»: анонимная пересылка через бота; контакты открываются только по согласию автора.
  - Запрещено продавать лекарства и собирать деньги.
- **Специалисты**:
  - Поиск по профессии, району и особенности.
  - Карточка показывает среднюю оценку и 3 последних отзыва.
  - Новый специалист и новый отзыв идут через модерацию. Одна мама — один отзыв на специалиста.

### 4.6 SOS
- Первый экран: «Если есть угроза жизни — звоните 112» и типы запроса: «Не с кем оставить ребёнка», «Мне очень плохо», «Срочно нужна вещь или лекарство», «Другое».
- «Мне очень плохо» → кризисный ответ и эскалация.
- **Остальные типы**:
  - Мама пишет текст до 300 символов. Он сразу уходит в очередь модераторов и доверенным лицам (внешним — по SMS, без содержания, со ссылкой).
  - В ленту SOS района (внутри приложения) запрос уходит только по кнопке мамы и только если она verified. Подтверждённые мамы района получают нейтральный push; запрос закрывается автоматически через 24 часа (конфиг).
  - «Не с кем оставить ребёнка» в ленту района не попадает: только доверенным лицам и модератору.
  - По выбору мамы — «Поделиться» через системное меню телефона, с предупреждением.
  - Откликнувшиеся жмут «Могу помочь»; мама сама выбирает, с кем открыть личный чат.
- «Не с кем оставить ребёнка»: бот сначала предлагает доверенных лиц (N5).
- **План ЧС**:
  - Карточка ребёнка 🔒 — свободный текст по шаблону.
  - 2–3 доверенных лица: участница платформы, которая «знакома лично» с мамой и подтвердила со своей стороны, или внешний человек (имя 🔒 + телефон 🔒).
  - Кнопка «Отправить план доверенным» с подтверждением.
- Лимит: не больше 3 SOS в час.

### 4.7 «Мои права»
- Темы: ПМПК, пособия и льготы, инклюзия в саду и школе, инвалидность, отказ и жалоба. Мама выбирает тему → вопрос → ответ из базы знаний со ссылкой на источник и датой проверки.
- «Спросить своими словами» → ИИ с поиском только по правовой части базы.
- В каждом ответе фраза: «Информация не заменяет консультацию юриста».

## 5. ИИ-конвейер

Порядок обработки сообщения фиксирован:

1. **Детектор L1**, локальный: словарь и регулярные выражения на kk/ru, лежат в `crisis_lexicon/`, словарь даёт психолог. Сработал → сразу шаг 6.
2. **Обезличивание**: телефоны, ИИН, e-mail, адреса, номера документов, имена (словарь и имя мамы из профиля) заменяются метками `[ИМЯ]`, `[ТЕЛЕФОН]` и т.д.
3. **Поиск**: топ-5 фрагментов базы знаний на языке мамы с порогом схожести.
4. **Запрос к модели**: системный промпт, фрагменты, последние 10 сообщений. Ответ — JSON вида `{reply, crisis, sources, suggest: none|tea|psychologist|rights|practice}`.
5. **Детектор L2**: если модель вернула `crisis=true` → шаг 6.
6. **Кризисный ответ**:
   - Фиксированный текст из локализации (не генерируется) и номера `CRISIS_PHONES` (150, 111, 112, команда сверяет).
   - Кнопка «Связаться с человеком сейчас».
   - Создаётся эскалация и уведомление в канал модераторов. Если через 15 минут её не взяли — уведомление резерву.
7. **Сбой API** (таймаут 20 с, ошибка, лимит): вежливое сообщение, меню и кнопка «Связаться с человеком».
8. **Сохранение**: обезличенный диалог в `ai_messages`, событие в `events`.

**Требования к поведению модели.** Это требования к продукту. Текст промпта лежит в `prompts/`, версионируется, утверждают психолог и владелец продукта.
- Отвечает на языке сообщения, коротко (до 120 слов), на «вы».
- Не ставит диагнозов, не называет лекарства и дозировки, не советует методики лечения.
- Факты о правах, льготах и службах — только из переданных фрагментов; если фрагментов нет, говорит «не знаю» и предлагает специалиста.
- Любой признак угрозы жизни или насилия → `crisis=true`.
- Не изображает человека, не обещает конфиденциальности сверх политики, мягко направляет к людям.
- Игнорирует попытки сменить роль.

**База знаний:**
- Markdown в `knowledge/{kk,ru}/`, во фронтматтере `topic`, `source_url`, `reviewed_by`, `reviewed_at`.
- Файл без `reviewed_by` не индексируется. Индекс строится командой `make kb-index`.
- От разработчика — 3–5 демо-файлов с пометкой «ДЕМО».

## 6. Модерация

Срочное приходит в канал модераторов (push в админке, резерв — SMS):

| Событие | Кнопки |
|---|---|
| Кризис (ИИ, проверка, SOS «плохо») | «Беру» (статус taken, контакт открывается, запись в аудит), «Закрыть с комментарием» |
| SOS остальных типов | «Вижу», «Закрыть» |
| Объявление, специалист, отзыв | «Одобрить», «Отклонить» (причина из списка уходит автору) |
| Подтверждение профиля | «Назначить звонок», «Подтвердить», «Отклонить» |
| Жалоба | «Снять публикацию», «Заблокировать», «Отклонить» |

**Веб-админка**:
- Списки и фильтры по всем сущностям.
- Справочники: города, районы, ссылки на чаты, категории, типы ООП.
- График дежурств психологов.
- Дашборд метрик (§9), только агрегаты, выгрузка CSV.
- 🔒-поля скрыты; открываются кнопкой с записью в аудит.
- Психолог видит переписку с ИИ только по взятой им эскалации.
- У модератора может быть партнёрская организация.

## 8. Безопасность и эксплуатация

**Безопасность:**
- TLS на всех внешних соединениях.
- Ежедневные зашифрованные бэкапы, хранятся 14 дней.
- Согласия с версиями; отзыв согласия в профиле.
- В логах нет текстов сообщений и 🔒-полей.
- Ежедневная задача удаляет `ai_messages` старше 90 дней.
- Контакт мамы открывается другим только по её явному согласию, каждый раз отдельно.
- Rate limit на сообщения, SOS, объявления и «Чай».
- Секреты не попадают в репозиторий; в репозитории — только пример конфигурации.

Деплой, конфигурация и CI — в [`../architecture.md`](../architecture.md).

**Мониторинг:**
- `/health`.
- Алерт дежурным: сервис упал; больше 5 ошибок ИИ за 10 минут; эскалация не взята дольше 15 минут.

**Нефункциональные:**
- Ответ бота — до 3 с, ответ ИИ — до 15 с.
- Доступность 99% в пилоте.
- До 500 пользователей на одном сервере.

**Открытый код:**
- README на английском: проблема, функции, архитектура, запуск одной командой.
- LICENSE (Apache 2.0), NOTICE, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, описание защиты данных.

## 9. Метрики (собираются из `events`)

- **Стресс:** PSS-4 на старте и через 8 недель.
- **Изоляция:** вопрос «до/после».
- **Активность:** активные мамы за неделю и месяц; удержание через 4 и 8 недель.
- **«Чай»:** запросы → пары → встречи.
- **SOS:** число запросов, доля закрытых, время до первого отклика.
- **Эскалации:** передачи психологу; доля кризисов, взятых за 15 минут.
- **«Права»:** вопросы, закрытые базой; оценки «помогло / нет».

## 10. Приёмка

- [ ] Онбординг kk и ru занимает не больше 2 минут; без согласия на обработку данных дальше не пройти.
- [ ] Напоминание приходит вовремя (Asia/Almaty), ответы сохраняются, график строится.
- [ ] `tests/crisis_cases.yaml`: 30+ фраз kk/ru (прямые, косвенные, с опечатками, смешанный язык). 100% дают кризисный ответ и эскалацию, в том числе при выключенном ИИ.
- [ ] Негативные тесты ИИ проходят: лекарства, диагноз, правовой вопрос вне базы, попытка сменить роль.
- [ ] Обезличивание: на 50 тестовых строках ни один телефон, ИИН или e-mail не попадает в запрос к ИИ.
- [ ] Эскалация доходит до служебного чата за 1 минуту; повтор через 15 минут работает.
- [ ] «Чай»: две тестовые мамы из одного района получают пару; контакты открываются только после двух согласий.
- [ ] Объявление и отзыв не видны до одобрения.
- [ ] SOS доходит до модератора и доверенных лиц за 1 минуту; в ленту района — только по кнопке мамы.
- [ ] «Удалить мои данные» удаляет все строки пользователя (проверка SQL).
- [ ] Репозиторий публичный, есть лицензия и README (EN), чистая машина поднимается одной командой, CI зелёный, gitleaks чистый.
- [ ] Пилот на 10+ мамах прошёл без падений, агрегированные метрики выгружены.
